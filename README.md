Parfums D’ Parfums

Aplicación web para una perfumería ubicada en Calbuco, Chile, desarrollada con Django y PostgreSQL.

Este proyecto continúa el trabajo de la primera evaluación de Programación Backend e incorpora almacenamiento de datos, administración y operaciones CRUD desde una interfaz web.
Funcionalidades

    Catálogo público con nombre, categoría, precio, formato y disponibilidad.
    Creación, edición y eliminación de perfumes para usuarios administradores.
    Carga opcional de imágenes al crear o editar productos.
    Confirmación antes de eliminar y borrado únicamente mediante POST.
    Sección Nosotros con historia, valores y guía de perfumes.
    Formulario de contacto que guarda consultas.
    Administración de perfumes y consultas desde Django Admin.
    Validación de formularios y protección CSRF.

Tecnologías

    Python y Django.
    PostgreSQL.
    Psycopg para la conexión a PostgreSQL.
    Pillow para procesar imágenes.
    HTML y CSS.
    Git y GitHub.

Las versiones y dependencias están definidas en requirements.txt.
Requisitos

    Python compatible con la versión de Django indicada en requirements.txt.
    PostgreSQL instalado y en ejecución.
    Git.
    Una base de datos PostgreSQL creada para el proyecto.

La entrega incluye el repositorio y un informe PDF con:

    Problemática y justificación del modelo seleccionado.
    Estructura de las aplicaciones.
    Conexión a PostgreSQL sin mostrar credenciales.
    Migraciones y operaciones en Django Admin.
    Capturas del CRUD y sus validaciones.
    Resultados de pruebas y errores corregidos.
    Registro de preguntas, decisiones y verificaciones realizadas con IA.
    Conclusiones y reflexión del equipo.
